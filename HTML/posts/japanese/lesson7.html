📖 みんなの日本語　第七課

授受・手段・完了｜あげます・もらいます・もう～ました
文法 ①
名词(工具/手段) + で + 动词
道具/手段 + で + 動詞

意义：表示做某事使用的手段或工具。

箸でご飯を食べます。→ 用筷子吃饭。

日本語でレポートを書きます。→ 用日语写报告。

💡 第五课学了交通工具+で，这一课是工具和语言手段。
文法 ②
词/句 + は + ～ごで + 何ですか
～は日本語で何ですか

意义：询问某个词或句子用其他语言怎么说。

"Thank You"は日本語で何ですか。→ “Thank You”用日语怎么说？

"ありがとう"です。→ 是“ありがとう”。

文法 ③
～に～をあげます / 貸します / 教えます
相手 + に + 物/情報 + を + あげる/貸す/教える

意义：给某人提供物品或信息（给予/借出/教）。

木村さんに花をあげます。→ 送给木村先生花。

李さんに本を貸します。→ 借书给小李。

山田さんに英語を教えます。→ 教山田英语。

💡 「に」表示接受对象（给谁/借给谁/教谁）。
文法 ④
～に～をもらいます / 借ります / 習います
相手 + に + 物/情報 + を + もらう/借りる/習う

意义：从某人那里接收物品或信息（收到/借来/学习）。

木村さんに花をもらいました。→ 收到了木村先生的花。

ワンさんにCDを借ります。→ 从小王那里借CD。

佐藤さんに英語を習います。→ 跟佐藤学英语。

💡 「に」表示提供对象（从谁那里收到/借来/学习）。
文法 ⑤
もう + 动词ます形 + ました
もう + Vました

意义：表示动作已经完成/结束了。

もう荷物を送りましたか。→ 行李已经寄走了吗？

はい、もう送りました。→ 是的，已经寄走了。

いいえ、まだ送っていません。→ 不，还没寄走。

💡 否定回答用「まだ～ていません」表示“还没…”。
文法 ⑥
助词省略

意义：在对话中，当前后文能明确语义时，可以省略助词。

このスプーン(は)、素敵ですね。→ 这个勺子真漂亮。

コーヒー(を)、もう一杯いかがですか。→ 咖啡再来一杯怎么样？

💡 口语中常见，让对话更自然流畅。
