📖 みんなの日本語　第十課

存在・位置・列举｜あります/います・に・や・など
文法 ①
あります / います（存在）

📦 あります

用于无生命体征的事物

桜があります
有樱花树

公園があります
有一个公园

👤 います

用于有生命体征的人/动物

男がいます
有一个男人

犬がいます
有一条狗

💡 记住：有生命的用「います」，无生命的用「あります」。
文法 ②
场所 + に + 名词 + が + あります/います
場所 + に + N + がある/いる

意义：表示“在（场所）里有（名词）”。存在场所后接「に」。

ミラーさんは事務所にいます。→ 米勒先生在事务所里。

地下に何がありますか。→ 地下有什么？

レストランがあります。→ 有餐厅。

受付に誰がいますか。→ 接待处有人吗？

木村さんがいます。→ 木村先生在。

💡 疑问词「何」「誰」后接「が」而不是「は」。
文法 ③
名词 + は + 场所 + に + あります/います
N + は + 場所 + にある/いる

意义：陈述某物在某处（双方都知道的东西）。

東京ディズニーランドは千葉県にあります。→ 东京迪士尼乐园在千叶县。

東京ディズニーランドはどこですか。→ 东京迪士尼乐园在哪？

千葉県です。→ 在千叶县。

💡 也可以用「名词 + は + 场所 + です」来陈述位置。
文法 ④
名词 + の + 位置名词
N + の + 上/下/前/後ろ/左/右/中/外/隣/間

意义：表示方位。位置名词后接「に」表存在场所，接「で」表动作场所。

机の上に写真があります。→ 桌子上有照片。

本屋は花屋とスーパーの間にあります。→ 书店在花店和超市中间。

駅の近くで友達に会いました。→ 在车站附近遇到了朋友。

💡 常用方位词：上・下・前・後ろ・左・右・中・外・隣・間・近く
文法 ⑤
や / や～など（列举）
N + や + N + (など)

意义：「と」列举全部，「や」选择性列举部分事物。「など」表示“…等”。

箱の中に手紙や写真があります。→ 盒子里有信和照片等。

箱の中に手紙や写真などがあります。→ 盒子里有信、照片什么的。

💡 「や」暗示还有其他未列举的事物。
文法 ⑥
〜ですか（重复确认）
重复信息 + か

意义：重复对方说的话，表示确认。

すみません、アジアストアはどこですか。→ 不好意思，亚洲超市在哪？

アジアストアですか、あのビルの中です。→ 亚洲超市吗？在那栋楼里。

📌 第十課 キーワード
ありますいます 上・下・前・後ろ左・右・中・隣 やなど

📖 语法核心：ある/いる区别・存在句・方位词・や列举・重复确认
