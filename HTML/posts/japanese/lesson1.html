📖 みんなの日本語　第一課

初対面・自我介绍｜名词句基础
文法 ①
名词A + は + 名词B + です
N1 は N2 です

意义：「N1 是 N2」。用于描述身份、职业、事物属性。

私は学生です。→ 我是学生。

ミラーさんは会社員です。→ 米勒先生是公司职员。

💡 助词「は」读作「wa」，提示主题。「です」是敬体结尾，表判断。
文法 ②
名词A + は + 名词B + じゃありません / ではありません
N1 は N2 じゃありません

意义：「N1 不是 N2」。「です」的否定形式。

李さんは医者じゃありません。→ 小李不是医生。

私は教師ではありません。→ 我不是老师。

💡「じゃありません」口语常用；「ではありません」书面/正式。
文法 ③
名词A + は + 名词B + ですか
N1 は N2 ですか

意义：「N1 是 N2 吗？」。句尾「か」表疑问。

ミラーさんは社員ですか。→ 米勒先生是职员吗？

はい、社員です。→ 是的，是职员。

いいえ、社員じゃありません。→ 不，不是职员。

💡 回答「はい」肯定，「いいえ」否定。疑问句句尾读升调。
文法 ④
名词A + も + 名词B + です
N1 も N2 です

意义：用于陈述相同的事，相当于“也”。

私は学生です。森さんも学生です。→ 我是学生，森先生也是学生。

💡「も」代替「は」，强调同类。
文法 ⑤
名词A + の + 名词B
N1 の N2

意义：表示所属、属性、内容等，相当于“的”。

これは私の本です。→ 这是我的书。

文法 ⑥
～さん / ～ちゃん

意义：表达敬意或亲切的称呼后缀。

田中さん→ 田中先生/女士

花子ちゃん→ 小花（对小孩/亲密称呼）

💡 不能加在自己名字后。「あなた」不礼貌，尽量少用。
📌 第一課 キーワード
