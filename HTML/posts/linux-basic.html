🐧 Linux常用命令入门指南

📅 2025-05-20 🏷️ Linux / 基础必备 ✍️ 奈欢yu

Linux 命令行是每个开发者和运维人员必须掌握的核心技能。本文整理了最常用的 Linux 命令，帮助初学者快速上手。

📁 文件与目录操作

命令说明示例
ls列出目录内容ls -la
cd切换目录cd /home/user
pwd显示当前路径pwd
mkdir创建目录mkdir myfolder
rm删除文件/目录rm -rf folder/
cp复制文件cp file1.txt file2.txt
mv移动/重命名mv old.txt new.txt

🔍 文件查看与编辑

  • cat filename - 查看完整文件内容
  • less filename - 分页查看（支持上下滚动）
  • head -n 10 filename - 查看文件前10行
  • tail -n 10 filename - 查看文件后10行
  • vim filename - 使用 Vim 编辑器

🚀 系统与进程管理

# 查看系统信息
uname -a
cat /etc/os-release

# 查看进程
ps aux | grep nginx
top

# 杀死进程
kill -9 PID号

# 查看磁盘使用情况
df -h
du -sh 目录名/

💡 小贴士：man 命令名 可以查看任意命令的详细帮助文档，这是学习 Linux 最可靠的方式！

🌐 网络相关命令

命令说明
ifconfig / ip addr查看网络接口信息
ping测试网络连通性
netstat -tunlp查看端口占用
curl发送 HTTP 请求
wget下载文件

📝 总结

以上是 Linux 常用命令的快速参考。建议你每天练习几个命令，逐步形成肌肉记忆。熟能生巧，坚持练习会看到明显的进步！
