📖 みんなの日本語　第二十九課

結果状態・完了・方向｜ています・てしまう・に・それ
文法 ①
动词て形 + います（结果状态持续）
Vています（結果状態）

意义：表示因为某个动作发生后，结果状态一直保持。

窓が割れています。→ 窗户碎了。

💡 与第14课的「正在进行」不同，这里是强调结果状态的持续。
文法 ②
动词て形 + しまいました / しまいます（完成）
Vてしまいました（已完成）/ Vてしまいます（将来完成）

意义：表示动作已经完成（有“做完了/结束了”的感觉）。

宿題はもうやってしまいました。→ 作业已经写完了。

昼ご飯までにレポートを書いてしまいます。→ 我要在午饭前写完报告。

💡 「てしまう」在口语中常缩略为「ちゃう」。
文法 ③
名词(场所) + に + 行きます / 来ます / 帰ります
場所 + に + 移動動詞

意义：除了助词「へ」，助词「に」也可以表示移动的方向（去/来/回的目的地）。

どこかで財布を落としてしまったんです。→ 不知道在哪把钱包弄丢了。

それは大変ですね、すぐ交番に行かないと。→ 那可糟了，得赶紧去派出所。

文法 ④
それ / その / そう（指代内容）
それ / その + N / そう

意义：除了指代物品，也可以指代对方刚说过的内容（那件事）；文章里也可以指代前文内容。

来月は大阪の会社に転勤なんです。→ 下个月起，我就要转职到大阪了。

それはおめでとうございます。→ 那恭喜你了。

文法 ⑤
ありました（找到了/有了）
(Nが) ありました

意义：表示“找到了/有了”，常省略主语。

かばんがありました。→ 包找到了。

💡 与第10课的「あります」（存在）不同，这里强调“找到”的结果。
文法 ⑥
どこかで / どこかに
どこかで / どこかに

意义：「どこか、なにか」后面的「へ」「を」可以省略，但「で」「に」不能省略。

どこかで財布をなくしてしまいました。→ 不知道在哪把钱包搞丢了。

どこかに電話がありますか。→ 哪里有电话？

💡 「どこかへ」「どこかを」可以省略为「どこか」；但「どこかで」「どこかに」必须保留助词。
📌 第二十九課 キーワード
ています（結果）てしまう に（方向）それ ありましたどこかで

📖 语法核心：结果状态・てしまう完成・に方向・それ指代・ありました・どこかで/どこかに
