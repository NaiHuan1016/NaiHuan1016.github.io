📖 みんなの日本語　第二十八課

ながら・習慣・し｜同时进行・习惯・并列・承接
文法 ①
动词ます形 + ながら + 动词
Vます + ながら、V

意义：表示“一边……一边……”，两个动作同时发生。

音楽を聴きながら食事します。→ 一边听歌一边吃饭。

文法 ②
动词て形 + います / いました（习惯・反复）
Vています / Vていました

意义：表示习惯性、反复性的动作。现在的习惯用「ています」，过去曾经的习惯用「ていました」。

毎朝ジョギングをしています。→ 每天早上都跑步。

こどものとき、毎晩8時に寝ていました。→ 小时候，每晚八点睡觉。

文法 ③
普通形 + し、普通形 + し
普通形 + し、普通形 + し

意义：用于列举多个同类情况，也常用来为后面结论铺垫理由（“既……又……”）。

鈴木さんはピアノも弾けるし、歌も歌えるし、ダンスもできます。→ 铃木先生既会弹钢琴，也会唱歌，还会跳舞。

ここは値段も安いし、魚も新しいし、よく食べに来ます。→ 这里价钱便宜，鱼又新鲜，所以经常来吃。

文法 ④
それで / それに
それで（所以/因此）
それに（而且/并且）

意义：「それで」把前半句作为原因引出结果；「それに」表示递进补充。

ここはコーヒーも美味しいし、食事もできるし、それで人気があるんですね。→ 这里咖啡好喝，还可以吃饭，所以很受欢迎。

文法 ⑤
〜とき + 助詞
〜とき + は / に / の / など

意义：「とき」是名词，后面可以接助词表达更细致的语气与关系。

勉強するときは、音楽を聞きません。→ 学习的时候不听音乐。

疲れたときやさびしいとき、よく田舎の青い空を思い出します。→ 累或寂寞的时候，常常想起家乡的蓝天。

📌 第二十八課 キーワード
ながらています しそれで それにとき

📖 语法核心：ながら（同时）・ていました（过去习惯）・し（列举/理由）・それで/それに・とき+助词
